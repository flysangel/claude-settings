# Contract: CLAUDE.md 的結構

測試 `tests/unit/test_claude_md.py` 依這份約定檢查 `home/CLAUDE.md`。

```markdown
# <標題>

## 溝通

- <要求>
  預期：<可觀察的行為>

## Git

- <要求>
  預期：<可觀察的行為>

## 規格驅動開發

<前言：新功能走 Spec Kit，不改變行為的小改動除外>

- <要求>
  預期：<可觀察的行為>
```

約定：

1. 二級標題恰好三個，名稱與順序如上。
2. 每個頂層清單項目（行首為 `- `）是一條規則，下一個非空行 MUST 以兩個空白加「預期：」開頭。
3. 出現的 `sdd-<名稱>` MUST 全部屬於 6 個 skill 的清單；六個名稱 MUST 都至少出現一次。
4. 不得出現 `sdd-derive`。
5. 不得出現電子信箱、以 `/home/`、`/Users/` 開頭的路徑或 `C:\` 這類磁碟路徑。
6. UTF-8、LF、結尾有換行；不含 CR。
